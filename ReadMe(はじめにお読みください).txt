===============================================
  黒瀬瑠璃sample
===============================================

■ 起動方法
フォルダ内の「黒瀬瑠璃sample.exe」を実行してください。
※ フォルダごと配置してください（exe単体では動作しません）。

■ 操作方法
・クリック / Enter / スペース … テキストを進める
・画面右下のメニュー … オート / スキップ / 一時停止 / ウィンドウ消去 / チェックポイント(CP) / 設定
・「一つ前に回帰する」… 直前へ戻る
・セーブ … 自動セーブ（exe と同じフォルダの save/ に保存されます）
・終了 … ウィンドウを閉じてください

■ 推奨環境
・Windows 10 / 11（64bit）
・横画面（フルHD 1920×1080 推奨）
